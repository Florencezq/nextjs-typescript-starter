# H5 英语单词学习项目 PRD

## 1. 项目概述

本项目是一个面向移动端 H5 的英语单词学习应用。用户可以在首页浏览单词书，登录后进入单词学习流程，系统根据用户最近学习记录和学习进度，从上次学习位置继续学习。应用底部固定 2 个 Tab：「首页」和「我的」。

项目基于当前 Next.js App Router 代码实现，登录和注册能力参考现有页面：

- `app/login/page.tsx`：使用 `signIn('credentials')` 完成邮箱密码登录。
- `app/register/page.tsx`：使用 `getUser` 判断邮箱是否存在，使用 `createUser` 创建用户。
- `app/auth.ts`：NextAuth Credentials Provider，基于邮箱密码校验用户。
- `app/db.ts`：当前已有 `User` 表创建、查询和注册逻辑。

## 2. 目标

### 2.1 用户目标

- 用户可以快速选择一本单词书开始学习。
- 登录用户可以从最近学习位置继续学习。
- 用户可以查看自己的学习进度。
- 未登录用户在尝试学习时，可以通过弹窗完成登录或注册，不离开当前 H5 主流程。

### 2.2 产品目标

- 提供一个极简、低干扰的背单词体验。
- 通过「最近学习」降低继续学习成本。
- 用登录态保存用户进度，为后续复习、错词、统计等能力预留基础。

## 3. 范围

### 3.1 本期包含

- H5 底部双 Tab 导航：首页、我的。
- 首页单词书列表。
- 登录用户首页展示最近学习模块。
- 未登录用户点击单词书后跳转到「我的」并弹出登录弹窗。
- 邮箱密码登录和注册。
- 我的页面展示用户邮箱、退出登录、学习进度。
- 单词学习页：按单词卡片学习，支持下一个。
- 单词详情页：展示单词详细信息。
- 用户学习进度记录，包括最近学习单词书、当前学习位置、已学习数量。

### 3.2 本期不包含

- 发音播放的真实音频服务接入。
- 复杂复习算法，例如艾宾浩斯、错词重练、熟词标记。
- 第三方登录。
- 支付、会员、排行榜、社交分享。
- 管理后台和在线编辑单词书。

## 4. 用户角色与状态

### 4.1 未登录用户

- 可以浏览首页的所有单词书。
- 点击任意单词书时，进入「我的」页面并弹出登录弹窗。
- 可以在弹窗中切换登录和注册。
- 登录或注册成功后，可以回到原本想学习的单词书并开始学习。

### 4.2 已登录用户

- 可以浏览所有单词书。
- 如果有学习记录，首页展示「最近学习」模块。
- 点击「最近学习」或单词书，可以进入学习页。
- 可以在「我的」查看邮箱、退出登录和学习进度。

## 6.4 单词学习页

### 功能要求

- 用户必须登录才能进入学习页。
- 页面按单词卡片方式展示当前单词。
- 从最近学习单词的下一个开始：
  - 如果用户从未学习过该书，从第一个单词开始。
  - 如果最近学习单词是最后一个，则可以展示完成状态，或从最后一个保持完成提示。建议展示完成状态。
- 单词卡片尽可能简单。
- 本期单词卡片只展示一个示例句。
- 用户可以点击「下一个」切换到下一个单词。
- 用户可以点击单词标题进入单词详情页。
- 点击「下一个」后需要更新学习进度。

### 单词卡片字段建议

基于给定 JSON，学习页建议使用以下字段：

- `headWord`：主单词，例如 `adrift`。
- `content.word.content.ukphone`：英式音标，例如 `əˈdrɪft`。
- `content.word.content.usphone`：美式音标，例如 `ə'drɪft`。
- `content.word.content.trans[0].pos`：词性，例如 `adj`。
- `content.word.content.trans[0].tranCn`：中文释义，例如 `漫无目的地；漂浮着`。
- `content.word.content.sentence.sentences[0].sContent`：英文例句。
- `content.word.content.sentence.sentences[0].sCn`：中文例句。

## 8. 数据需求

## 8.1 单词数据结构

给定单词 JSON 可作为单词数据源的基础结构。建议在业务层归一化为以下模型，便于渲染：

```ts
type Word = {
  wordRank: number;
  headWord: string;
  bookId: string;
  wordId: string;
  ukphone?: string;
```

## 8.3 学习进度数据结构

建议新增用户学习进度表或等价存储结构：

```ts
type UserBookProgress = {
  id: number;
  userId: number;
  bookId: string;
  currentWordRank: number;
  currentWordId: string;
  learnedCount: number;
  totalWords: number;
  lastStudiedAt: Date;
  createdAt: Date;
  updatedAt: Date;
};
```

### 字段说明

- `userId`：关联当前登录用户。
- `bookId`：单词书 ID，例如 `Level4_1`。
- `currentWordRank`：最近完成学习的单词排序。
- `currentWordId`：最近完成学习的单词 ID。
- `learnedCount`：已学习数量。
- `totalWords`：单词书总数，方便进度展示。
- `lastStudiedAt`：最近学习时间，用于首页最近学习和我的页排序。

### 进度计算规则

- 下一次学习单词 = 当前单词书中 `wordRank > currentWordRank` 的第一个单词。
- 如果没有进度记录，从 `wordRank` 最小的单词开始。
- 如果 `currentWordRank` 已经是最后一个单词，展示完成状态。
- `learnedCount` 不应超过 `totalWords`。

## 10. 登录注册实现要求

### 登录

- 表单字段与现有 `Form` 组件一致：`email`、`password`。
- 服务端调用方式参考：

```ts
await signIn('credentials', {
  redirectTo: targetUrl,
  email,
  password,
});
```

- H5 Popup 内建议封装为可复用认证组件，而不是直接跳转到 `/login`。
- 登录失败时需要展示错误信息，不应让用户停留在无反馈状态。

### 注册

- 服务端逻辑参考：

```ts
const user = await getUser(email);

if (user.length > 0) {
  return 'User already exists';
}

await createUser(email, password);
```

- 注册成功后建议直接调用登录逻辑，完成自动登录。
- 如果保持现有注册成功跳转登录页的方式，也需要在 H5 中明确提示用户继续登录。

### 退出登录

- 调用现有 `signOut`。
- 退出后首页不展示最近学习，我的页回到未登录态。

## 11. 状态与异常处理

### 11.1 加载状态

- 读取会话时展示页面级 loading 或骨架。
- 读取单词书列表时展示列表骨架。
- 登录、注册、退出登录、点击下一个保存进度时，按钮进入 loading 状态并防止重复提交。

### 11.2 空状态

- 首页无单词书：展示「暂无单词书」。
- 已登录但无最近学习：不展示最近学习模块。
- 我的页无学习进度：展示「还没有学习记录」和「去首页选择单词书」。

### 11.3 错误状态

- 登录失败：提示「邮箱或密码错误」。
- 注册邮箱已存在：提示「该邮箱已注册，请直接登录」。
- 单词书不存在：展示错误页或返回首页入口。
- 单词数据为空：提示「这本单词书暂无可学习单词」。
- 保存进度失败：提示用户重试，当前卡片不应直接跳过。

## 12. UI 与体验原则

- 视觉保持轻量、干净，适合高频学习。
- 单词卡片页面尽量减少元素，只突出单词、释义和一个例句。
- 主要按钮固定在内容底部附近，便于单手点击。
- 文案使用中文，英文只用于单词、音标、例句等学习内容。
- 字体层级清晰：
  - 单词标题最大。
  - 释义其次。
  - 例句和辅助信息较小。
- H5 页面注意安全区，底部按钮或 Tab 不被系统手势遮挡。

## 13. 验收标准

### 首页

- 未登录用户进入首页时，只能看到单词书列表。
- 未登录用户点击单词书后，会跳转到我的页并自动弹出登录 Popup。
- 已登录且有学习记录的用户，可以看到最近学习模块。
- 已登录但无学习记录的用户，不展示最近学习模块。
- 所有单词书都能正常展示。

### 我的

- 未登录时展示登录/注册入口。
- 登录 Popup 可以完成邮箱密码登录。
- 注册 Popup 可以完成邮箱密码注册。
- 已登录时展示当前用户邮箱。
- 已登录时展示学习进度。
- 点击退出登录后，会切换为未登录态。

### 学习页

- 未登录用户不能直接进入学习页。
- 首次学习某单词书时，从第一个单词开始。
- 有进度时，从最近学习单词的下一个开始。
- 单词卡片展示单词、音标、词性、中文释义和一个例句。
- 点击下一个后，单词切换且进度被保存。
- 学到最后一个单词后，展示完成状态。

### 详情页

- 点击学习页单词后，可以进入详情页。
- 详情页展示释义、例句、同近义词等更完整信息。
- 点击返回后，可以回到学习页并保持学习位置。
